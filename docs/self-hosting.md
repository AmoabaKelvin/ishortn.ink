# Self-hosting iShortn

The self-hosting guide is published with the rest of the docs at `/docs/self-hosting`. Its source
is [`content/docs/self-hosting.mdx`](../content/docs/self-hosting.mdx), which renders on GitHub
too.

It covers the Cloudflare resources to create (starting from
[`wrangler.example.jsonc`](../wrangler.example.jsonc)), environment variables, database setup,
deploys, cron jobs, Clerk, domains, optional features, the health check and upgrades.
