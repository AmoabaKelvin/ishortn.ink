---
title: Update a link
description: Change a short link's destination, alias, expiry or activation time.
endpoint:
  method: PATCH
  path: /api/v1/links/{alias}
---

Updates one short link in your personal workspace. Send only the fields you want to change. The change takes effect for visitors straight away.

## Request

| Parameter | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alias` | path | string | Yes | The link's current alias. |
| `domain` | query | string | No | The link's domain. Defaults to your default domain, or `isht.app`. See [Domains](/docs/api#domains). |

The JSON body takes at least one of these fields:

| Field | Type | Description |
| --- | --- | --- |
| `url` | string | New destination. Must be a valid absolute URL. It goes through the [link safety check](/docs/abuse#link-safety-checks) again. |
| `alias` | string | New alias, 1 to 20 characters: letters, numbers, `-` and `_`. The old alias stops working. |
| `expiresAt` | string \| null | Expiry date as ISO 8601 with a time zone, such as `2026-12-31T23:59:59Z`. `null` removes it. |
| `activatesAt` | string \| null | Activation time as ISO 8601 with a time zone. Setting a time requires Pro or Ultra; `null` removes it on any plan. |
| `expiresAfter` | integer \| null | Click limit, a whole number above 0. `null` removes it. |

Any other field, such as `password` or `domain`, is rejected with `400`. To change those, edit the link in the dashboard.

<CodeGroup>

```bash title="cURL"
curl "https://ishortn.ink/api/v1/links/launch-day?domain=isht.app" \
  -X PATCH \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/blog/launch-day-recap",
    "expiresAt": null
  }'
```

```javascript title="JavaScript"
const response = await fetch(
  "https://ishortn.ink/api/v1/links/launch-day?domain=isht.app",
  {
    method: "PATCH",
    headers: {
      "x-api-key": process.env.ISHORTN_API_KEY,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      url: "https://example.com/blog/launch-day-recap",
      expiresAt: null,
    }),
  },
);

if (!response.ok) {
  throw new Error(`${response.status}: ${await response.text()}`);
}

const link = await response.json();
```

```python title="Python"
import os

import requests

response = requests.patch(
    "https://ishortn.ink/api/v1/links/launch-day",
    params={"domain": "isht.app"},
    headers={"x-api-key": os.environ["ISHORTN_API_KEY"]},
    json={
        "url": "https://example.com/blog/launch-day-recap",
        "expiresAt": None,
    },
)

if not response.ok:
    raise RuntimeError(f"{response.status_code}: {response.text}")

link = response.json()
```

</CodeGroup>

## Response

`200 OK` with the updated link, in the same shape as [Get a link](/docs/api/get-link#response).

```json
{
  "shortLink": "https://isht.app/launch-day",
  "url": "https://example.com/blog/launch-day-recap",
  "alias": "launch-day",
  "expiresAt": null,
  "activatesAt": null,
  "expiresAfter": null
}
```

## Errors

| Status | Body | Cause |
| --- | --- | --- |
| `400` | `Invalid request body` | The body isn't valid JSON. |
| `400` | JSON list of validation issues | A field has the wrong type or format, or the body has a field that isn't listed above. |
| `400` | `No update fields provided` | The body is an empty object. |
| `400` | A [link safety](/docs/abuse#link-safety-checks) message | The new destination failed the safety check. |
| `401` | `Invalid or missing API key` | See [Authentication](/docs/api#authentication). |
| `403` | `{"error": "API access requires Pro", "upgrade_url": "https://ishortn.ink/pricing"}` (JSON) | The key's account isn't on Pro or Ultra and its notice period has ended. See [API access by plan](/docs/api#api-access-by-plan). |
| `403` | `Domain not available for this API key` | `domain` isn't a platform domain or an active custom domain in your personal workspace. |
| `403` | `Scheduled links are only available on Pro and Ultra plans` | Setting `activatesAt` on the Free plan. |
| `404` | `Link not found` | No link with that alias on that domain in your personal workspace. |
| `409` | `Alias already exists for this domain` | The new alias is taken on that domain. |
| `500` | `Failed to update link due to a server error` | An unexpected server error. Retry later. |
| `429` | `Rate limit exceeded. Retry in N seconds.` | See [Rate limits](/docs/api#rate-limits). |
