---
title: Create a link
description: Shorten a URL, optionally with your own alias, domain, expiry, password, schedule or UTM parameters.
endpoint:
  method: POST
  path: /api/v1/links
---

Creates a short link in your personal workspace and counts it toward your monthly link limit.

## Request

Send a JSON body with `Content-Type: application/json` and your key in `x-api-key`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `url` | string | Yes | The destination. Must be a valid absolute URL, such as `https://example.com/page`. |
| `alias` | string | No | The path after the domain. Letters, numbers, `-` and `_`, up to 20 characters, and at least 6 characters on the Free plan. Must not already exist on the domain (checked case-insensitively). Defaults to a random 9-character alias. |
| `domain` | string | No | The domain for the link. Defaults to your default domain, or `isht.app`. See [Domains](/docs/api#domains). |
| `expiresAt` | string | No | Date and time after which the link stops redirecting, as an ISO 8601 string such as `2026-12-31T23:59:59Z`. |
| `expiresAfter` | number | No | Number of clicks after which the link stops redirecting. |
| `activatesAt` | string | No | Date and time the link starts redirecting, as an ISO 8601 string with a time zone (`Z` or an offset such as `+01:00`). Pro and Ultra only. |
| `password` | string | No | Visitors must enter this password before they're redirected. Pro and Ultra only. Stored as a bcrypt hash. |
| `utmParams` | object | No | UTM parameters added to the destination when the link is visited. Pro and Ultra only. See below. |

`utmParams` accepts these optional string fields, each up to 255 characters: `utm_source`, `utm_medium`, `utm_campaign`, `utm_term` and `utm_content`.

Fields not in this table are ignored. Folders, tags, notes, targeting rules and the other dashboard settings can't be set through the API yet.

## Response

`201 Created` with the new link.

| Field | Type | Description |
| --- | --- | --- |
| `id` | number | The link's ID. It never changes, even when the link is renamed, so use it to tell links apart. |
| `shortLink` | string | The full short URL, `https://<domain>/<alias>`. |
| `url` | string | The destination URL. |
| `alias` | string | The alias, either yours or the generated one. |
| `createdAt` | string \| null | When the link was created, in ISO 8601 UTC. `null` for some older links. |
| `expiresAt` | string \| null | When the link expires, or `null`. |
| `activatesAt` | string \| null | When the link starts redirecting, or `null`. |
| `expiresAfter` | number \| null | Click limit, or `null`. |
| `isProtected` | boolean | `true` when the link has a password. |

```json
{
  "id": 4907,
  "shortLink": "https://isht.app/launch-day",
  "url": "https://example.com/blog/launch-day",
  "alias": "launch-day",
  "createdAt": "2026-11-21T18:45:12.000Z",
  "expiresAt": null,
  "activatesAt": null,
  "expiresAfter": 1000,
  "isProtected": false
}
```

## Errors

Error bodies use the [standard error shape](/docs/api#responses-and-errors), except the plan-gated `403`.

| Status | Code | Message | Cause |
| --- | --- | --- | --- |
| `400` | `invalid_json` | `Request body must be valid JSON` | The body isn't valid JSON. |
| `400` | `validation_failed` | `Request body is invalid` | A field has the wrong type, or `url` isn't a valid URL, or `activatesAt` isn't an ISO 8601 date with a time zone. `details` lists the fields. |
| `400` | `bad_request` | `Alias can only contain alphanumeric characters, dashes, and underscores` | The alias has other characters. |
| `400` | `bad_request` | `This alias is reserved. Choose another one.` | The alias matches an iShortn app route on that domain. |
| `400` | `bad_request` | `Custom aliases must be at least 6 characters on the free plan. Upgrade to Pro for shorter aliases.` | Free plan with a short alias. |
| `400` | `bad_request` | A [link safety](/docs/abuse#link-safety-checks) message | The destination failed the safety check. |
| `401` | `unauthorized` | `Invalid or missing API key` | See [Authentication](/docs/api#authentication). |
| `403` | | `{"error": "API access requires Pro", "upgrade_url": "https://ishortn.ink/pricing"}` (whole body) | The key's account isn't on Pro or Ultra and its notice period has ended. See [API access by plan](/docs/api#api-access-by-plan). |
| `403` | `forbidden` | `Your account is restricted. Contact safety@ishortn.ink` | Your account has been restricted. |
| `403` | `forbidden` | `Domain not available for this API key` | `domain` isn't a platform domain or an active custom domain in your personal workspace. |
| `403` | `forbidden` | `Your plan includes 3 custom domains, so links.example.com can't take new or edited links. Upgrade to Ultra to keep using it.` | `domain` is a custom domain beyond your plan's allowance, for example after a downgrade. Without custom domains on your plan the message is `Custom domains are available on Pro and Ultra. Upgrade to create or edit links on links.example.com.` |
| `403` | `forbidden` | `Scheduled links are only available on Pro and Ultra plans` | `activatesAt` on the Free plan. |
| `403` | `forbidden` | `You need to upgrade to a pro plan to use password protection` | `password` without Pro or Ultra. |
| `403` | `forbidden` | `UTM parameters are available on Pro and Ultra plans. Please upgrade to use this feature.` | `utmParams` on the Free plan. |
| `403` | `forbidden` | `You've reached your monthly limit of 30 links. Upgrade to Pro for more.` | Free plan monthly limit. On Pro the message names the 1,000-link limit and suggests Ultra. |
| `409` | `conflict` | `Alias already exists` | The alias is taken on that domain, compared case-insensitively. Aliases of deleted or renamed links on platform domains stay taken. |
| `429` | `rate_limited` | `Rate limit exceeded. Retry in N seconds.` | See [Rate limits](/docs/api#rate-limits). |
| `500` | `internal_error` | `An unexpected error occurred` | The alias is longer than 20 characters, or an unexpected server error. |
