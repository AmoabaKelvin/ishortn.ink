---
title: Link analytics
description: Get click totals, a daily series and breakdowns by country, city, device, browser, OS and referrer for one short link.
endpoint:
  method: GET
  path: /api/v1/analytics/{alias}
---

Returns the click analytics for one short link in the key's workspace, over the date range the dashboard allows for your plan: the link's whole history on Pro and Ultra, and <PlanValue plan="free" cap="analyticsRangeLimitDays" /> on Free.

## Request

| Parameter | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alias` | path | string | Yes | The link's alias. |
| `domain` | query | string | No | The link's domain. Defaults to your default domain, or `isht.app`. See [Domains](/docs/api#domains). |

<CodeGroup>

```bash title="cURL"
curl "https://ishortn.ink/api/v1/analytics/launch-day?domain=isht.app" \
  -H "x-api-key: YOUR_API_KEY"
```

```javascript title="JavaScript"
const response = await fetch(
  "https://ishortn.ink/api/v1/analytics/launch-day?domain=isht.app",
  { headers: { "x-api-key": process.env.ISHORTN_API_KEY } },
);

if (!response.ok) {
  const { error } = await response.json();
  throw new Error(`${response.status}: ${error.message ?? error}`);
}

const stats = await response.json();
console.log(`${stats.totalClicks} clicks`);
```

```python title="Python"
import os

import requests

response = requests.get(
    "https://ishortn.ink/api/v1/analytics/launch-day",
    params={"domain": "isht.app"},
    headers={"x-api-key": os.environ["ISHORTN_API_KEY"]},
)
response.raise_for_status()

stats = response.json()
print(f"{stats['totalClicks']} clicks")
```

</CodeGroup>

## Response

`200 OK`. Every `clicksPer…` field is an object that maps a value to its click count. Values with no clicks are left out, so an object can be empty. When a value can't be detected, its clicks are counted under `Unknown`. Clicks from known bots aren't recorded.

| Field | Type | Description |
| --- | --- | --- |
| `totalClicks` | number | All clicks in `window`, including clicks older than raw-data retention. |
| `verifiedClicks` | number | Clicks confirmed to come from a real browser. Counted only while [verified clicks](/docs/short-links#verified-clicks) are on. |
| `clicksPerDate` | object | Clicks per UTC day, keyed `YYYY-MM-DD`, oldest first. |
| `uniqueClicksPerDate` | object | New unique visitors per UTC day, keyed `YYYY-MM-DD`, oldest first. |
| `verifiedClicksPerDate` | object | Verified clicks per UTC day. |
| `clicksPerCountry` | object | Clicks per country name, such as `Ghana`. |
| `clicksPerCity` | object | Clicks per city name. |
| `clicksPerContinent` | object | Clicks per continent name, such as `Africa`. |
| `clicksPerDevice` | object | Clicks per device type, such as `mobile`, `tablet` or `desktop`. |
| `clicksPerOS` | object | Clicks per operating system. |
| `clicksPerBrowser` | object | Clicks per browser. |
| `clicksPerModel` | object | Clicks per device model, such as `iPhone`. |
| `clicksPerReferrer` | object | Clicks per source, such as `Direct`, `Twitter` or `instagram.com`. Visits without a referrer count as `Direct`. |
| `window` | object | The date range the numbers cover. `days` is the plan's range in days, or `null` for all time. `from` is the start (ISO 8601), or `null` for all time. `to` is the time of the request. |

Every number covers only clicks inside `window`. Raw click data is kept for a limited time on Free and Pro (see [Analytics](/docs/analytics#how-long-data-is-kept)). After that, each day is kept as a daily total. `totalClicks`, `clicksPerDate` and `uniqueClicksPerDate` include those daily totals. The breakdowns and the verified counts cover only the clicks whose raw data is still kept.

## Errors

Error bodies use the [standard error shape](/docs/api#responses-and-errors), except the plan-gated `403`.

| Status | Code | Message | Cause |
| --- | --- | --- | --- |
| `401` | `unauthorized` | `Invalid or missing API key` | See [Authentication](/docs/api#authentication). |
| `403` | | `{"error": "API access requires Pro", "upgrade_url": "https://ishortn.ink/pricing"}` (whole body) | The key's account isn't on Pro or Ultra and its notice period has ended. See [API access by plan](/docs/api#api-access-by-plan). |
| `403` | `forbidden` | `Domain not available for this API key` | `domain` isn't a platform domain or an active custom domain in the key's workspace. |
| `404` | `not_found` | `Link not found` | No link with that alias on that domain in the key's workspace. |
| `429` | `rate_limited` | `Rate limit exceeded. Retry in N seconds.` | See [Rate limits](/docs/api#rate-limits). |
