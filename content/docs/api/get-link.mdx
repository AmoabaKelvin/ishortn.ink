---
title: Get a link
description: Look up a short link in the key's workspace by its alias.
endpoint:
  method: GET
  path: /api/v1/links/{alias}
---

Returns the destination and settings of one short link.

## Request

| Parameter | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alias` | path | string | Yes | The link's alias, such as `launch-day`. |
| `domain` | query | string | No | The link's domain. Defaults to your default domain, or `isht.app`. See [Domains](/docs/api#domains). |

<CodeGroup>

```bash title="cURL"
curl "https://ishortn.ink/api/v1/links/launch-day?domain=isht.app" \
  -H "x-api-key: YOUR_API_KEY"
```

```javascript title="JavaScript"
const response = await fetch(
  "https://ishortn.ink/api/v1/links/launch-day?domain=isht.app",
  { headers: { "x-api-key": process.env.ISHORTN_API_KEY } },
);

if (response.status === 404) {
  console.log("No such link");
} else if (!response.ok) {
  const { error } = await response.json();
  throw new Error(`${response.status}: ${error.message ?? error}`);
} else {
  const link = await response.json();
  console.log(link.url);
}
```

```python title="Python"
import os

import requests

response = requests.get(
    "https://ishortn.ink/api/v1/links/launch-day",
    params={"domain": "isht.app"},
    headers={"x-api-key": os.environ["ISHORTN_API_KEY"]},
)
response.raise_for_status()

print(response.json()["url"])
```

</CodeGroup>

## Response

`200 OK` with the link.

| Field | Type | Description |
| --- | --- | --- |
| `id` | number | The link's ID. It never changes, even when the link is renamed, so use it to tell links apart. |
| `shortLink` | string | The full short URL, `https://<domain>/<alias>`. |
| `url` | string | The destination URL. |
| `alias` | string | The alias. |
| `createdAt` | string \| null | When the link was created, in ISO 8601 UTC. `null` for some older links. |
| `expiresAt` | string \| null | When the link expires, or `null`. |
| `activatesAt` | string \| null | When the link starts redirecting, or `null`. |
| `expiresAfter` | number \| null | Click limit, or `null`. |

```json
{
  "id": 4907,
  "shortLink": "https://isht.app/launch-day",
  "url": "https://example.com/blog/launch-day",
  "alias": "launch-day",
  "createdAt": "2026-11-21T18:45:12.000Z",
  "expiresAt": "2026-12-31T23:59:59.000Z",
  "activatesAt": null,
  "expiresAfter": null
}
```

## Errors

Error bodies use the [standard error shape](/docs/api#responses-and-errors), except the plan-gated `403`.

| Status | Code | Message | Cause |
| --- | --- | --- | --- |
| `401` | `unauthorized` | `Invalid or missing API key` | See [Authentication](/docs/api#authentication). |
| `403` | | `{"error": "API access requires Pro", "upgrade_url": "https://ishortn.ink/pricing"}` (whole body) | The key's account isn't on Pro or Ultra and its notice period has ended. See [API access by plan](/docs/api#api-access-by-plan). |
| `403` | `forbidden` | `Domain not available for this API key` | `domain` isn't a platform domain or an active custom domain in the key's workspace. |
| `404` | `not_found` | `Link not found` | No link with that alias on that domain in the key's workspace. |
| `429` | `rate_limited` | `Rate limit exceeded. Retry in N seconds.` | See [Rate limits](/docs/api#rate-limits). |
