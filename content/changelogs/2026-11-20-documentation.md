The iShortn documentation now lives at [ishortn.ink/docs](/docs). It replaces the old external docs site, and links to `docs.ishortn.ink` will forward to the matching page.

## Guides

There's a guide for each part of iShortn: [short links](/docs/short-links) and all their options, [platform domains](/docs/platform-domains), [custom domains](/docs/custom-domains) with DNS setup step by step, [QR codes](/docs/qr-codes), [link-in-bio pages](/docs/bio-pages), [analytics](/docs/analytics), [teams](/docs/teams) and [CSV import](/docs/bulk-import). Each one says which plan a feature needs, and [Plans and limits](/docs/plans) puts every limit in one table.

## API reference

The [API reference](/docs/api) covers every endpoint: authentication, request fields, response examples, error messages and the plan rules that apply. Each endpoint has examples in cURL, JavaScript and Python.

## Find things fast

Press `⌘K` (or `Ctrl K`) on any docs page to search the guides and the API reference. Code examples have a copy button, and the docs follow your light or dark theme.
